# Умный ремонт

Платформа для ремонта квартир: сметы, фотоотчёты бригад, поэтапная оплата через безопасную сделку банка.
Требования — «ТЗ Lean MVP 2.3». Работа идёт спринтами по 2 недели, каждый спринт приходит отдельным pull request.

## Как запустить у себя

Нужен только [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
docker compose up --build
```

Через пару минут откройте **http://localhost:3000**.

- Войти администратором: телефон `+7 999 000-00-01`. Настоящие СМС пока не отправляются — код показывается прямо на экране входа.
- Любой другой номер входит как обычный заказчик.
- Документация API: http://localhost:8000/api/docs

Остановить — `Ctrl+C` или `docker compose down`. Стереть локальную базу — `docker compose down -v`.

Другие телефоны администраторов можно задать в файле `.env` (образец — `.env.example`).

## Из чего состоит

| Папка | Что внутри |
|---|---|
| `backend/` | API на Python (FastAPI), база PostgreSQL 16, миграции Alembic, тесты |
| `web/` | Сайт: вход, личный кабинет, админка (Next.js) |
| `docs/` | Архитектура и план спринтов |

Подробнее: [docs/architecture.md](docs/architecture.md), [docs/roadmap.md](docs/roadmap.md).

## Проверки

Каждый pull request автоматически проверяется на GitHub: линтер, тесты backend (покрытие не ниже 80%),
сверка миграций с моделями, сборка сайта и Docker-образов.

Запустить тесты локально: `make up`, затем `make test`.
