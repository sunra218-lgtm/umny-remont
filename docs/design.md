# Умный дизайн-проект

Заказчик на странице объекта открывает «Дизайн-проект»:

1. **Стиль.** Скандинавский, минимализм, лофт, неоклассика или японди.
2. **План БТИ.** Загружает PDF, JPEG или PNG. Если включено чтение плана, помещения и площади
   берутся из экспликации, иначе заготавливаются по площади квартиры. Заказчик может их поправить.
3. **Отделка.** Для каждой комнаты сервис подбирает пол, стены, потолок, дверь, плинтус, свет и
   сантехнику из каталога платформы (`design_materials`) под выбранный стиль. Заказчик меняет любую
   позицию. Его выбор закрепляется и не сбрасывается при смене стиля.
4. **Стоимость.** Чистовые материалы считаются целыми упаковками с запасом на подрезку. Черновые
   материалы (грунт, шпаклёвка, плиточный клей, гидроизоляция) и работы считаются по ценам из
   справочника расценок, а если позиции там нет, по ценам по умолчанию. Итог показывается вилкой ±15 %.
5. **Картинки и ролик.** По умолчанию комната рисуется схемой в цветах и рисунках отделки. Если
   включён YandexART, нейросеть рисует фотореалистичные картинки. Ролик заказывается у внешнего
   контент-завода.

Каталог отделки ведут администратор и менеджер закупок (`POST/PUT /api/v1/design/materials`).
Стартовый каталог загружается командой `python -m app.seed`.

## Что уходит наружу

- **В Yandex Vision OCR:** только файл плана.
- **В YandexART и контент-завод:** стиль, названия и площади комнат, названия, цвета и рисунки
  материалов, примерная сумма.

Имена, телефоны и адрес объекта наружу не передаются. Яндекс Облако хранит данные в РФ.

## Настройки (`deploy/.env`)

| Переменная | Значения |
|---|---|
| `DESIGN_PLAN_READER` | `manual` (по умолчанию) или `yandex_ocr` |
| `DESIGN_RENDERER` | `preview` (по умолчанию) или `yandexart` |
| `YANDEX_FOLDER_ID`, `YANDEX_API_KEY` | Каталог и ключ сервисного аккаунта с ролями `ai.vision.user` и `ai.imageGeneration.user` |
| `CONTENT_FACTORY_URL`, `CONTENT_FACTORY_KEY` | Адрес и ключ контент-завода. Пока адрес пуст, кнопки ролика нет |

## Обмен с контент-заводом

Платформа обращается к контент-заводу с заголовком `Authorization: Bearer <CONTENT_FACTORY_KEY>`.

**Заказ ролика.** Запрос `POST {CONTENT_FACTORY_URL}/jobs`:

```json
{
  "project_id": "…",
  "version": 7,
  "style": "scandi",
  "total_rub": 1250000,
  "rooms": [
    {
      "room": "Гостиная",
      "type": "living",
      "area_m2": 18.2,
      "finishes": {
        "floor": {"title": "Ламинат 33 кл. «Дуб нордик»", "color": "#D9C7A7", "pattern": "plank"},
        "walls": {"title": "Краска матовая «Белый лён»", "color": "#EEE9DF", "pattern": "paint"}
      }
    }
  ]
}
```

Ответ: `{"id": "<номер задания>"}`.

**Статус ролика.** Фоновый процесс раз в минуту запрашивает `GET {CONTENT_FACTORY_URL}/jobs/{id}`.
Ответ: `{"status": "processing" | "done" | "failed", "video_url": "https://…"}`.

- `video_url` принимается только по https. Плеер на сайте открывает его напрямую.
- Если ролик не готов за двое суток, заказ считается неудачным.
- Любая правка отделки делает прежний ролик устаревшим.
