# Безопасность перед пилотом (спринт 7)

Самопроверка перед внешним пентестом базового уровня (ТЗ 2.3, раздел 10). Пентест проводит внешняя
компания на сервере пилота; этот список — что уже проверено и что им показать.

## Сделано

| Область | Как защищено | Где проверяется |
|---|---|---|
| Вход | Код из СМС: 5 попыток, пауза 60 с, не больше 5 кодов в час на телефон и 30 на IP | `tests/test_auth.py` |
| Сессии | Access-токен 15 минут в памяти, refresh в httpOnly cookie; у бригады refresh подписан ключом телефона | `tests/test_auth.py`, `tests/test_field.py` |
| Ссылка для бригады | Одноразовая, 30 минут; повторное открытие не работает; устройства можно отозвать | `tests/test_field.py` |
| Доступ к объектам | Каждый запрос проверяет роль на объекте; чужой объект отвечает 404, а не 403 | тесты всех модулей |
| Деньги | Выплата только из резерва под блокировкой строки, сумма выплат равна резерву, повтор по акту невозможен, спор замораживает | `tests/test_payments_acts.py`, `tests/test_procurement_disputes.py` |
| Повторы запросов | Idempotency-Key обязателен для изменяющих запросов | `tests/test_idempotency.py` |
| Вебхук банка | Подпись HMAC, без неё 401 | `tests/test_payments_acts.py` |
| Файлы | Фото проверяются по содержимому (JPEG/WebP), размер ограничен, выдаются по ссылке на 15 минут с подписью | `tests/test_field.py` |
| Частота запросов | 300 в минуту и 60 изменяющих с одного IP; IP ставит Caddy, подделать заголовок снаружи нельзя | `tests/test_protection.py` |
| Заголовки | CSP без внешних источников, HSTS, запрет встраивания в чужие сайты, nosniff, no-store для API | `tests/test_protection.py`, проверено на стенде |
| Настройки сервера | Сервер не запустится со стандартными секретами, без HTTPS-адреса или с показом кода на экране | `tests/test_protection.py` |
| Описание API | На сервере `/api/docs` выключено | `tests/test_protection.py` |
| Журнал | Изменения смет, актов, платежей и статусов пишутся в журнал, который нельзя изменить или удалить на уровне БД | `tests/test_admin.py` |
| Зависимости | `pip-audit` и `npm audit` — 0 известных уязвимостей (Next.js обновлён до 15.5.29, React до 19.1.10) | 27.11.2026 |

## Осталось до пилота на реальных людях

- Модель угроз и уровень защищённости ИСПДн (ожидаемо УЗ-3), уведомление Роскомнадзора — юрист.
- Внешний пентест базового уровня на сервере пилота.
- Подключить SMS-шлюз: до этого код входа виден только в журнале сервера.
- Сбор ошибок фронтенда (self-hosted Sentry или аналог в РФ) и оповещения — после выбора провайдера сервера.
