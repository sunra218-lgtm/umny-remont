# Подключение Т-Банка

Платформа работает с банком через один интерфейс (`app/modules/payments/bank.py`).
Т-Банк реализован в `app/modules/payments/tbank.py` и включается настройкой `BANK_BACKEND=tbank`.
Остальной код от выбора банка не зависит.

## Как идут деньги

| Шаг | Что делает платформа | Запрос к банку |
|---|---|---|
| Резерв этапа или заказа материалов | Выставляет счёт, заказчик платит по ссылке (СБП или карта) | `Init` с `CreateDealWithType=NN` — открывается сделка |
| Оплата прошла | Этап готов к работе | уведомление `CONFIRMED`, номер сделки `SpAccumulationId` |
| Акт подписан обеими сторонами | Выплата подрядчику (и платформе, если есть комиссия) | e2c `Init` с `DealId`, `PartnerId`, затем `Payment`; последняя — `FinalPayout` |
| Деньги зачислены | Этап оплачен, акт закрыт | уведомление e2c `COMPLETED` |
| Спор | Выплата не отправляется, деньги ждут на счёте сделки | — |
| Спор решён возвратом | Деньги возвращаются заказчику | `Cancel` |

Уведомления банк шлёт на `https://<домен>/api/v1/webhooks/bank`; платформа проверяет подпись
(`Token`) паролем того терминала, от которого пришло уведомление, и отвечает `OK`.

## Что нужно от владельца проекта

1. Договор с Т-Банком: интернет-эквайринг с «Безопасной сделкой» (мультирасчёты) и выплаты.
2. Два терминала — приём оплаты и выплаты (e2c). Сначала тестовые: ключ заканчивается на `DEMO`.
3. Регистрация получателей выплат в банке: платформа, каждый подрядчик и поставщик.
   Код получателя (`PartnerId`) администратор вносит в карточке организации в админке.
   Код платформы — в `TBANK_PLATFORM_PARTNER_ID`.

Ключи и пароли терминалов вносятся только в `deploy/.env` на сервере. В чат, почту и git их не отправлять.

## Включение

```
BANK_BACKEND=tbank
TBANK_TERMINAL_KEY=...DEMO
TBANK_PASSWORD=...
TBANK_PAYOUT_TERMINAL_KEY=...DEMO
TBANK_PAYOUT_PASSWORD=...
TBANK_PLATFORM_PARTNER_ID=...
```

После перезапуска (`docker compose ... up -d`) — прогон на тестовых терминалах: резерв этапа,
оплата тестовой картой банка, акт, выплата, спор с возвратом. Поля API в адаптере сверены
с открытым описанием Т-Банка; если в тестовом контуре банк ответит иначе, правка — в одном файле
`tbank.py`. Боевые ключи ставятся вместо тестовых, когда прогон пройден.
